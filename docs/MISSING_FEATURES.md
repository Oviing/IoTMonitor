# Missing Features

The following capabilities are not included in the current v1 release:

- Persistent historical storage
- Alerting and configurable warning/critical thresholds
- OPC UA certificate-based authentication
- Encrypted credential storage and application access control
- Automated tests, linting, type checking, formatting, and CI
- Complete keyboard navigation and screen-reader live announcements
- Comprehensive loading and actionable error states

## Suggested priority

1. Automated tests and CI
2. Credential security and access control
3. Persistent history
4. Alerting and thresholds
5. Accessibility improvements
